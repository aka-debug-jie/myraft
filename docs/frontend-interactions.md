## 连线与分组的具体取舍

现在由可用像素决定是否显示完整单环，不再在16节点处强制切换矩阵。节点沿椭圆等弧长分布；布局检查节点间距、中心空间以及关系端口间隔。Leader 的外围编号槽位保留，换届后旧 Leader 返回自己的槽，不占用新 Leader 的原槽。首次展示预置与后续两次独立快照确认仍分开。

空间不足时进入**可读分组**，每组是按固定成员 ID 排列的浏览范围，必要时额外显示真实 Leader。上一组、下一组、搜索和键盘可覆盖所有成员，界面显示当前范围和总数。分组不是 Raft 成员、不是中继，也没有绘制“组主干”。这是对汇流建议的保守实现，避免把汇总图形误解为实际网络链路。可切换“全部缩略”观察全体节点；缩略时隐藏不可读的小编号，点击“聚焦”或“可读分组”恢复阅读。

连线只来自新鲜、身份有效的 Follower 报告，并且目标必须是同任期的有效 Leader。未知、不可达、跨任期不补画警示连接。图例的“可见关系/已观测关系”区分显示范围与实际采样，不将隐藏组内节点冒充离线。

在35个稳定单Leader测试组合中，当前可读组的全部有效关系均显示；可见节点无覆盖、无越界、字号至少11屏幕像素；采样检查无穿节点或边交叉，同目标中心端口间净距（扣除1.8px高亮线宽）至少6px。该结论不外推到所有任意视口、缩放和多Leader布局。缩略图明确不承诺逐线或逐编号阅读。

## 复现

源码构建与节点启动仍使用原README。以下浏览器脚本需要测试用Playwright/Chromium，产品运行仍仅需Go构建的可执行文件。

```bash
go build -o raft-node .
go build -o raft-console ./cmd/dashboard
./raft-console -node-bin ./raft-node -source-dir . -allow-control
# 页面打开后明确启用控制；按需创建会话。
python scripts/interaction_ui_test.py --url http://127.0.0.1:8080 --output new-evidence/interactions --synthetic-only
python scripts/group_ui_test.py --url http://127.0.0.1:8080 --output new-evidence/groups --synthetic-only
python scripts/copy_ui_test.py --output new-evidence/copy
python scripts/frontend_acceptance.py --dashboard ./raft-console --node ./raft-node --output new-evidence/matrix
python scripts/dashboard_e2e.py --dashboard ./raft-console --node ./raft-node --output new-evidence/classroom
```

所有真实测试使用独立目录，结束后清理自己创建的进程。原始配置、WAL和过程输出留在本机 `.tools/frontend-interactions-20261023`，历史目录不覆盖。

## 边界与剩余限制

- 本轮没有实现会产生“虚拟组边”的汇流、小地图或完整状态筛选器；采用可读分组、全体缩略和节点搜索解决密度问题。
- 分组切换改变展示范围；它不改变固定成员，也不改变多数派人数。任意缩放不保证所有编号同时可读。
- 窗口极小、缩略视图、多Leader观测仍可能需要主动聚焦；35组合不是所有屏幕的穷尽证明。
- 课堂步骤根据有限的任务回执窗口推导。长实验使早期停止回执被移出窗口后，指引可能保守地要求补充步骤；真实提交、当前校验和历史校验结果仍分别保留，不将缺失动作认作已完成。
- 诊断中的原始英文、协议字段及机器JSON仍保留，便于核查；正常动作、实验阶段和结果已有中文展示。
